# QA

## Sources

- [ ] 关键事实可追溯
- [ ] 事实、引用、观点和推测已区分
- [ ] 图片与外部素材已记录来源

## Copy

- [ ] 标题、封面和正文承诺一致
- [ ] 内容地图中的核心判断、论据、例子和结论已进入对应卡片
- [ ] 轻编辑没有改变原文含义、判断强度或个人经历性质
- [ ] 已完成中文去 AI 味检查
- [ ] 无编造数据、经历或引用

## Delivery Contract

- [ ] `brief.md` 已冻结内容类型、图片数量与职责、配文区块、标签、CTA 和平台操作边界
- [ ] 用户最新修正已同步到 Issue、`brief.md`、`copy.md` 和卡片计划
- [ ] 图片与配文各自承担已确认职责，没有错放提示词、教学、边界说明或核心信息
- [ ] 标签与 CTA 符合交付结构；明确不需要时已记录“无”
- [ ] 观点长文、工具科普或 AI 生图展示已采用对应内容类型规则

## Cards

- [ ] 输出为 1080 × 1440 PNG
- [ ] 每页一个核心意思
- [ ] 正文移动端可读，无遮挡、溢出和错误裁切
- [ ] 页码、细线等装饰元素即使轻微重叠，也没有遮挡正文
- [ ] 用户提供视觉参考时，已核对其真实尺寸和布局规律
- [ ] 新视觉路线已调研 3–5 个同平台、同主题、同形式候选，并记录来源
- [ ] 使用的模板 ID、`validated` / `candidate` 状态和使用前复核结果已记录
- [ ] 封面先表达目标受众可获得的具体结果，再呈现工具名、技术原理或抽象概念
- [ ] 文字型帖子优先使用 HTML/CSS；图片模型调用与已确认视觉方案一致
- [ ] 首图已重点检查标题层级、断行、边距和缩略图可读性
- [ ] 已同时检查原尺寸图片与手机缩略图，并逐张核对信息完整性
- [ ] 已逐张视觉检查

## Package

- [ ] 必需文件齐全
- [ ] manifest 状态真实
- [ ] 卡片数量与计划一致
- [ ] 正式内容包位于仓库的 `projects/issue-<number>-<slug>/`
- [ ] 研究、文案、适用时的 HTML 源文件、正式图片、预览图、生成日志和 QA 结果已被 Git 跟踪
- [ ] 远程任务分支包含当前核验提交
- [ ] 内容 PR 已创建或更新，base 为 `main`，文件范围与对应内容 Issue 一致
- [ ] 仓库中没有密钥、Cookie、私人来源或未获许可的素材
