# 小红书视觉模板库

本库只记录来源链接、版式骨架、适用内容和历史反馈，不保存或复制外部帖子截图、文字、品牌标识和其他受保护素材。正式使用前仍需打开来源重新核对当前页面、真实尺寸和适配性。

## 状态

- `validated`：已经在本项目的完成帖子中使用并经过用户修改确认；复用前仍需核对来源和当前内容是否适配。
- `candidate`：已完成初步调研，尚未经过本项目完整成品验证；必须先展示给用户选择，不得直接当作成熟模板批量生产。

## 使用流程

1. 根据内容类型筛选模板，不先按个人审美选风格。
2. 新视觉路线同时提供 3–5 个同平台、同主题、同形式候选。
3. 打开来源，核对真实尺寸、页数、层级、留白和重复结构；未知尺寸不得沿用历史猜测。
4. 用户选定后只复用版式骨架，不复制文字、品牌标识或外部素材。
5. 将模板 ID、状态、核对结果和必要调整写入 `brief.md`、`cards/plan.md` 与 `qa.md`。
