# 最终标题

好用的AI指令，别埋在聊天里

# 正文（含标签）

🗂️ 一次改对了，别只留在聊天记录里。
你让AI写周报，来回纠正了好几轮：少写过程、先讲结果、不要编数字。终于改顺了，下周开新对话，又要从头说一遍。

📝 把这次的修改提炼成任务说明。
不用安装新工具，普通文档就能存。留下四样东西：要完成什么、按什么顺序做、什么算合格、哪些错误别再犯。

📌 以周报为例，可以这样写。
输入：本周工作记录和真实数据。
结构：结果、问题、下周安排。
要求：保留项目名和时间；没有数据就标“待补充”。
检查：每项成果有没有依据，下周安排有没有负责人和时间。
再附上一小段你认可的范例，比十句“写专业一点”更具体。

🛠️ 让AI帮你整理，但由你定规则。
“请根据这次任务和我的修改，整理一份下次能复用的任务说明。包括输入材料、处理步骤、输出格式、检查清单。只保留已经明确的要求，把临时信息放到单独的‘本次输入’里。没有确认的偏好不要写成固定规则。”

🔄 下次使用时，换材料、留方法。
开新对话，把说明和本次资料一起给AI。遇到新错误就补一条检查；过时或重复的要求就删掉。文档可以手动复制，不依赖某个产品的记忆功能。

🔎 思路来自腾讯9月发布的AI工作方法。
其中提到把重复要求做成模板、清单和可复用技能。这里改成普通人也能维护的任务说明，不需要先学会配置Agent。
