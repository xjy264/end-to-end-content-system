# 标题

重复点网页的活，让Kimi学一次

# 正文（用户已确认）

🖱️ 每周都要点一遍的网页，值得交给AI试试。
打开几个网站，找到信息，复制到表格，下周再来一遍。这类工作步骤固定，却很容易把时间耗在切页面和搬数据上。

📌 Kimi的浏览器扩展，可以直接操作网页。
按照官方介绍，它能打开页面、点击按钮、填写表单和提取信息。装好扩展后，可以从浏览器侧边栏向Kimi交代任务。

🔁 有意思的是，你可以把操作录成一个技能。
官方提供了操作录制功能：把重复任务的步骤录下来，保存为可复用的Skill，也就是一套做事流程。下次遇到同类任务，就可以调用这份流程继续做。

🧩 比如，把“每周查看产品更新”变成固定任务。
可以这样交代：
“查看这5个产品的官网更新页，整理本周新增的功能、发布日期和来源链接。没有找到日期就写未标明，最后做成一张表。”

先把入口、需要的字段和输出格式说清楚，再考虑把流程保存下来。得到的表格可以继续用于周报、选题或产品对比。

🔍 第一次跑完，先检查它到底收集了什么。
链接是否正确，有没有把旧功能当成新更新，缺失信息有没有被猜出来。确认这套流程符合要求，再用它处理后续重复任务。网页改版后，也可能需要调整步骤。
