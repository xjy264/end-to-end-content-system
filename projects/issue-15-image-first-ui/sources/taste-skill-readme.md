## 与本帖有关的事实

1. README 将仓库描述为可移植的 Agent Skills，用于改善 AI 生成界面的布局、字体、动效和间距。
2. README 明确区分实现类 Skills 与图片生成类 Skills：实现类输出代码，图片生成类只输出视觉参考图。
3. README 建议把网页、移动端或品牌视觉参考图交给 Codex、Cursor 或 Claude Code 继续实现。
4. `image-to-code` 的示例流程是：先生成图片，再分析图片，最后编写代码。
5. README 使用 ChatGPT Images 或同类生成器作为示例，没有把 Taste Skill 描述成自带生图模型的平台。
