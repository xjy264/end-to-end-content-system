# 最终标题

先让AI问你，再让它干活

# 正文（含标签）

🎯 说不清需求，也可以开始用AI。
“帮我做个方案”最容易换来一份看着完整、用起来不对的回答。你还没讲清楚对象、预算和限制，它已经替你补完了一堆设定。

🗣️ 换个顺序，让AI先采访你。
不用一口气写长提示词。先说你想做什么，让它只追问会影响结果的信息；一轮两三个问题，答完再往下走。

🧩 比如，你想准备一场分享。
先别让它写20页大纲。让它问：听众是谁、讲多久、他们听完要会做什么、有哪些现成材料。给新手讲工具入门，和给同事讲项目复盘，需要的内容完全不同。

📋 这一段可以直接改着用。
“我想完成【任务】，但需求还不完整。请先采访我，每轮最多问3个会影响结果的问题。优先确认目标、对象、限制和完成标准。能从已有信息判断的不要重复问。信息够用后，整理成一份简短任务说明，列出仍需假设的地方，再给我初稿。”

📝 留下任务说明，下一次还能用。
把确认过的目标和偏好存进自己的文档，下次需要时再贴给AI。重要信息变了就更新，不必指望聊天工具自动、永久记住你。

🔎 方法参考Thariq在9月10日的分享。
原帖建议用采访补足上下文。这里把它收窄成“围绕当前任务提问”，再补上每轮问题数和完成标准，更适合日常写作、汇报、学习计划。
