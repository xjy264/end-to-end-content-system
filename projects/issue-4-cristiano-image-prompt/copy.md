一条提示词生成 C 罗史诗海报

## Body

### 完整提示词

> C罗主题收藏版史诗叙事海报。巨大的C罗写实侧脸剪影作为外轮廓，轮廓内部自然生长出清晨训练场、球员通道、足球轨迹、腾跃射门、弧形看台、聚光灯、风雨薄雾与金色光尘，所有动作剪影都是同一个C罗。高级剪影轮廓填充式叙事合成，双重曝光联想，电影海报与梦幻水彩插画融合；柔和空气透视、纸张颗粒、边缘飞白与刷痕，暗红、深黑、金色、草坪深绿，安静、宏大、诗意、传说感，大面积留白，克制高级，一眼识别足球与C罗主题。竖版，主体中部偏左。不要文字、数字、Logo、水印、品牌、队徽、比分、奖杯数量或无关人物。

### 提示词该怎么写

1. **主题别只填名字**：与其只写“C 罗”，不如写清你想表达的是自律、速度、成长还是荣耀。
2. **把抽象词换成场景**：“传奇”本身画不出来，训练场、通道、腾跃射门和球场聚光灯可以。
3. **说明画面关系**：我特别写了“所有动作剪影都是同一个 C 罗”，避免模型把叙事场景理解成一群球员。
4. **风格和材质分开写**：电影海报决定整体气质，水彩、纸张颗粒和边缘飞白决定画面触感。
5. **最后补排除项**：文字、Logo、队徽、比分和奖杯数量都容易制造错误信息，提前排除更稳妥。

真正值得复用的不是“C 罗”这两个字，而是这套顺序：**主题 → 外轮廓 → 内部世界 → 叙事关系 → 风格材质 → 排除项**。
