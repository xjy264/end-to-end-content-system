## Body

这次不是只把【主题】换成“C 罗”。

我把“传奇”继续拆成训练场、球员通道、动作轨迹和聚光灯，再告诉模型：这些动作剪影都属于同一个人。这样生成出来的画面才会真的围绕 C 罗展开，而不是套一张看起来很宏大的背景。

真正有用的不是多写几个“史诗、震撼、高级”，而是把抽象感觉翻译成模型看得见的场景、关系和材质。

### 完整生成提示词

> C罗主题收藏版史诗叙事海报。巨大的C罗写实侧脸剪影作为外轮廓，轮廓内部自然生长出清晨训练场、球员通道、足球轨迹、腾跃射门、弧形看台、聚光灯、风雨薄雾与金色光尘，所有动作剪影都是同一个C罗。高级剪影轮廓填充式叙事合成，双重曝光联想，电影海报与梦幻水彩插画融合；柔和空气透视、纸张颗粒、边缘飞白与刷痕，暗红、深黑、金色、草坪深绿，安静、宏大、诗意、传说感，大面积留白，克制高级，一眼识别足球与C罗主题。竖版，主体中部偏左。不要文字、数字、Logo、水印、品牌、队徽、比分、奖杯数量或无关人物。

## Card teaching copy

- 主题: C 罗的足球传奇、自律、速度与不断突破
- 外轮廓: C 罗清晰、坚定的巨大侧脸
- 内部世界: 训练场 → 球员通道 → 腾跃射门 → 聚光灯球场
- 叙事关系: 所有动作剪影都是同一个 C 罗
- 视觉融合: 双重曝光 × 电影海报 × 梦幻水彩
- 材质与色彩: 纸张颗粒、边缘飞白；暗红、深黑、金色、草坪绿
- 明确排除: 文字、Logo、队徽、比分、奖杯数量、无关人物
- 教学结论: 不要只替换【主题】。把抽象概念拆成能被看见的场景，模板才会真正强绑定主题。
