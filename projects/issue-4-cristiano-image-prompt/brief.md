# Brief

- Issue: https://github.com/xjy264/end-to-end-content-system/issues/4
- 目标受众: 对 AI 生图感兴趣、已会调用模型但仍主要依靠堆关键词的中文用户。
- 内容目标: 生产一篇小红书图文帖子；图片只展示 C 罗主题 AI 成品，帖子文字单独提供完整提示词与写法教学。
- 核心观点: 高质量提示词的价值不在长度，而在主体、构图、场景、风格、光线与约束各自承担明确作用。
- 语气: 直接、实用、有判断，不使用“万能公式”“一键封神”等夸张承诺。
- 视觉方向: 电影级运动海报；速度、力量、聚光灯与赛场叙事；单张 1080 × 1440 图片，不叠加教学文字。
- 表达边界: 不声称 C 罗参与或认可，不虚构体育事实，不呈现官方合作，不复制参考帖图片、排版或大段提示词。
- 已确认假设:
  - 最终是一篇“图片 + 帖子文字”的图文帖子。
  - 图片部分只交付一张 `gpt-image-2` 成品图，不把提示词或教学排进图片。
  - 文字部分在 `copy.md` 中提供完整生成提示词、提示词教学、标题、正文和标签。
  - 先生成 3 个内部候选，用户确认后只保留一个方向进入最终交付。
  - 使用当前项目流水线；能力缺口先记录，内容交付后另建改进 Issue。
  - 不执行平台发布。
