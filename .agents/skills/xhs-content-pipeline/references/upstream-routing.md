# Upstream Workflow Routing

Use upstream repositories as methods and references; do not copy their code into this repository.

- Topic, Hook, title diagnosis: `dbskill`.
- General sourced outline and draft: `content-research-writer`.
- Final Chinese humanization: `Humanizer-zh`.
- Deterministic text-led social cards: project HTML/CSS first; use `guizang-social-card-skill` when its confirmed layout fits the selected route.
- Alternative image-card and infographic route: `baoyu-skills`.
- Conceptual hand-drawn inserts: `ian-xiaohei-illustrations`.
- Deep research inspiration: `khazix-skills`, without copying its personal voice.
- NotebookLM: reference its grounded-research method only under the NewAPI-only rule.
- PPT: optional secondary display route. HTML/CSS: default route for text-led opinion, educational, and business-analysis cards.

Default chain: dbskill → research/writing → Humanizer-zh → HTML/CSS or confirmed social-card route → QA.
